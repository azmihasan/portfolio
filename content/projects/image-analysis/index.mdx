Computer vision is one of the most talked-about topics in AI today. Its use is already widespread, and the trend is still growing. 
Starting from basic image processing to more advanced tasks like object detection and instance segmentation, computer vision is being used in many areas. 
Now, with the help of large language models (LLMs) and multimodal AI, it’s becoming even more powerful and useful in real-world applications.

In my last bachelor thesis, I dived into computer vision, where I implemented an object detection algorithm to identify certain object by training an object detection model with custom dataset.
